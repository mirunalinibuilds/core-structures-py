## 📝 Problem Description
Given two integers `num1` and `num2`, return their sum.

- **Problem Link:** [LeetCode 2235 - Add Two Integers](https://leetcode.com)
- **Difficulty:** Easy
- **Purpose:** Daily Streak Maintenance

## 💻 Solution (Python)
```python
class Solution:
    def sum(self, num1: int, num2: int) -> int:
        return num1 + num2
```
